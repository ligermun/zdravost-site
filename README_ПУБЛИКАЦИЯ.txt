ЗДРАВОСТЬ — ВЕРСИЯ САЙТА ДЛЯ ПУБЛИКАЦИИ (18.11.2026)

Что входит:
- index.html — главная страница на основе найденного локального прототипа от 28.10.2026;
- blog/index.html — каталог пяти SEO-статей;
- blog/<slug>/index.html — каждая статья полностью, включая списки и таблицы;

На этом сайте НЕТ формы регистрации, приёма платежей или обработки персональных данных. Прежде чем рекламировать ПРОДАЖУ билетов, нужна действующая регистрация, достоверные сведения об организаторе и корректные условия покупки/возврата. Утверждённый состав спикеров и расписание в исходном прототипе отсутствуют.

БЕСПЛАТНАЯ ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Распаковать архив на компьютере.
2. Создать публичный GitHub-репозиторий, например zdravost-site.
3. Загрузить СОДЕРЖИМОЕ распакованной папки в корень репозитория: index.html, blog.css, robots.txt, папку blog.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. После публикации адрес будет вида https://USERNAME.github.io/zdravost-site/ .
6. Проверить открытие всех страниц по прямым ссылкам в России без VPN (лучше через знакомого или тестовый российский интернет), HTTP 200, мобильное меню, блог и переходы.
7. В Яндекс Вебмастере проверить страницу инструментом «Проверка ответа сервера». Доступность в РФ и модерацию Директа нельзя гарантировать заранее.

АЛЬТЕРНАТИВА: YANDEX CLOUD OBJECT STORAGE
Разместить всё содержимое в публичном бакете и включить статический хостинг. Возможны расходы по тарифам. Важно сохранить структуру директорий и index.html каждого раздела. Для красивого URL /blog/ может понадобиться настройка пути/проверка индексных страниц: если хостинг отдаёт 404 на пути каталога, нужно переключить URL на /blog/index.html, либо использовать поддерживающий directory indexes веб-сервер.

ПОСЛЕ ПОЛУЧЕНИЯ АДРЕСА
- Добавить фактические canonical URL и sitemap.xml с точным доменом (до публикации его нет).
- Настроить HTTPS, проверить что все URL открываются по HTTPS и без перенаправления через chatgpt.site.
- В объявлениях Яндекс Директа использовать публичную ссылку на новый сайт, а не старую ссылку chatgpt.site.
- Яндекс Вебмастер: проверить ответ сервера, robots.txt, метаданные, индексацию.
- SEO индексация в поиске НЕ является обязательным условием модерации объявления, но доступность посадочной страницы для проверяющего бота важна.

Документ с пятью статьями из архива исходных материалов использован как текстовая основа; редакторские служебные указания в статьи не перенесены.
